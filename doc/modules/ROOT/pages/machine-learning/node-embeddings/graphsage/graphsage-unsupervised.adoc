[[algorithms-graphsage-unsupervised-intro]]
== Introduction

GraphSAGE is a graph neural network (GNN) architecture outlined in the paper https://arxiv.org/pdf/1706.02216.pdf[_Inductive Representation Learning on Large Graphs_] by Hamilton et al. (2017).

This section covers the syntax used to execute the {algorithm} algorithm to generate embeddings for nodes in a graph.

NOTE: For node classification, see xref:machine-learning/node-property-prediction/graphsage-supervised.adoc[GraphSAGE supervised].

[.include-with-train]
======
.Run GraphSAGE unsupervised in train mode on a named graph.
[source, cypher, role=noplay]
----
CALL gds.graphSage.unsupervised.train(
  graphName: String,
  configuration: Map
)
YIELD
  preProcessingMillis: Integer,
  trainMillis: Integer,
  configuration: Map
----

include::partial$/algorithms/common-configuration/common-parameters.adoc[]

.Configuration
[opts="header",cols="3,2,3m,2,8"]
|===
| Name                  | Type           | Default              | Optional | Description
| activationFunction    | String         | "relu"               | yes      | The activation function to use. Valid values are "relu" and "sigmoid"
| aggregator            | String         | "mean"               | yes      | The neighborhood embedding aggregator to use. Valid values are "mean" and "max"
| batchSize             | Integer        | n/a                  | yes      | The number of target nodes to train on in each batch. If not provided, the algorithm will automatically infer the maximally allowed batch size within the constraints of available memory
| dropout               | Float          | 0.1                  | yes      | The dropout probability for each layer. Must be a value >= 0.0 and < 1.0
| embeddingDimension    | Integer        | 256                  | yes      | The node embedding dimension of the model layers' outputs
| epochs                | Integer        | n/a                  | no       | The number of epochs to train the model
| featureProperties     | List of String | n/a                  | no       | The names of the node properties that should be used as input features. All property names must exist in the projected graph and be of type Float or List of Float.
| jobId                 | String         | Generated internally | yes      | An ID to more easily track the algorithm’s progress.
| layerNormalization    | Boolean        | true                 | yes      | Whether to apply layer normalization between the model layers
| learningRate          | Float          | 0.001                | yes      | The learning rate for the optimizer
| modelName             | String         | n/a                  | no       | The name of the model to train (must be unique)
| negativeSamplingRatio | Float          | 1.0                  | yes      | The ratio of negative to positive samples to sample for training
| nodeLabels            | List of String | ["*"]                | yes      | Filter the named graph using the given node labels. Nodes with any of the given labels will be included.
| numNeighbors          | List           | [20 10]              | yes      | The number of neighbors to sample for each layer. Note that this also determines the number of layers
| numWalks              | Integer        | 10                   | yes      | The number of random walks to perform for each node in the graph
| randomSeed            | String         | n/a                  | yes      | A number used to seed all randomness of the computation
| relationshipTypes     | List of String | ["*"]                | yes      | Filter the named graph using the given relationship types. Relationships with any of the given types will be included.
| walkDepth             | Integer        | 3                    | yes      | The number of steps in every random walk
|===

.Results

|===
| Name                | Type    | Description
| preProcessingMillis | Integer | Milliseconds for preprocessing the graph.
| trainMillis         | Integer | Milliseconds to train the model.
| configuration       | Map     | The configuration used for running the algorithm.
|===
