[[node-property-prediction]]
= Node property prediction
:description: This chapter provides explanations and examples for the node property prediction pipelines in the Neo4j Graph Data Science library.

Node property prediction can be used for predicting either discrete labels or numerical values for nodes with supervised machine learning.
The Neo4j Graph Data Science library offers node property prediction both as standalone algorithms and as pipelines for end-to-end workflows.
